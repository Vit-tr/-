# Дневник Трейдера Опционов

Веб-приложение для ведения дневника опционной торговли с автоматической синхронизацией через Bybit API и ручным вводом сделок.

## Деплой на Vercel

### Шаг 1: Создайте аккаунт на Vercel
1. Перейдите на https://vercel.com
2. Зарегистрируйтесь через GitHub (рекомендуется)

### Шаг 2: Загрузите проект на GitHub
1. Создайте новый репозиторий на GitHub
2. Загрузите туда все файлы из папки `trader-journal`

### Шаг 3: Деплой
1. В Vercel нажмите "New Project"
2. Выберите ваш репозиторий с дневником
3. Vercel автоматически определит Vite проект
4. Нажмите "Deploy"

Готово! Ваш сайт будет доступен по адресу `https://ваш-проект.vercel.app`

## Локальный запуск

```bash
npm install
npm run dev
```

Откроется на http://localhost:3000

## Функционал

- ✅ Добавление сделок вручную (Straddle/Strangle)
- ✅ Автоматический расчет статистики
- ✅ Equity curve с drawdown
- ✅ Анализ по волнам Эллиотта
- ✅ Сравнение BTC vs ETH
- ✅ Интерактивные графики
- ✅ Сохранение в localStorage
- 🔄 Интеграция Bybit API (следующий этап)

## Технологии

- React 18
- Vite
- Zustand (state management)
- Recharts (графики)
- CSS с OKLCH цветами
